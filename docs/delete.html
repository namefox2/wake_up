계정 삭제

최종 수정일: 2026년 7월

앱 내에서 계정 삭제하기

  1. 1
    앱을 실행하고 하단의 설정 탭을 탭합니다.
  2. 2
    계정 섹션에서 계정 삭제를 탭합니다.
  3. 3
    확인 다이얼로그에서 삭제를 탭합니다.

⚠ 삭제 전 확인하세요

  • 계정 삭제 시 모든 연결, 알람, 슬롯 정보가 즉시 삭제됩니다.
  • 삭제된 데이터는 복구할 수 없습니다.
  • 유료 슬롯 구매 이력도 함께 삭제되며 환불되지 않습니다.

삭제되는 데이터

데이터 유형 보관 기간
Firebase 익명 인증 계정 즉시 삭제
기기 정보 (초대 코드, 연결 상태) 즉시 삭제
파트너 연결 정보 즉시 삭제
알람 데이터 즉시 삭제
슬롯 구매 정보 즉시 삭제
약관 동의 기록 (동의 일시, 버전, 기기 정보) 분쟁 해결 목적으로 보존
